저수준의 시스템 동작 원리부터 고트래픽 웹 서버의 동시성 제어, 그리고 수학적 추상화를 통한 객체지향 설계까지. 
겉핥기식 기술 사용을 지양하고, **"왜?"라는 질문을 통해 본질적인 문제를 해결**하는 것을 즐깁니다.

## 🛠️ Projects & Achievements

### 🎮 [웹 기반 1:1 고스톱 게임 서버](https://github.com/poming-matgo/poming_matgo_be)
> **트래픽 병목 해소 및 WebFlux 기반의 무결점 동시성 제어**
* **초저지연 I/O 아키텍처 설계** 
  * 분산 환경의 오버헤드를 줄이고자 Redis 의존성을 제거하고 `ConcurrentHashMap` 기반 로컬 데이터 구조로 개편.
  * I/O 병목 해소를 통해 **초당 72,000건의 웹소켓 메시지 유실 없이 처리 (기존 대비 약 6.6배 성능 향상)**.
* **ZGC 도입으로 지연 시간(Latency) 최적화**
  * 대규모 동시 접속 시 발생하는 GC STW(Stop-The-World)로 인한 끊김 현상 방지.
  * G1GC 대비 **P95 Latency를 112ms에서 66ms로 약 41% 개선**.
* **논블로킹 환경의 상태 정합성 보장**
  * 유저 입력과 서버 스케줄러 간의 충돌을 **CAS 연산 및 원자적 객체를 활용해 논블로킹으로 해결**.
  * 네트워크 지연 및 OS 시간 변경에 대비해 **서버 측 유예 시간 도입 및 Monotonic Clock 적용**으로 타임아웃 신뢰성 확보.
  * 중복 요청에도 데이터 정합성을 유지하는 상태 기반 방어 로직 설계.

### 📐 [대수학 기반 OOP 그래프 라이브러리](https://github.com/nhwgit/Algebraic-OOP-Graph)
> **추상대수학을 소프트웨어 설계 패턴으로 치환한 라이브러리**
* **대수학의 OOP 매핑:** 추상대수학의 `Monoid`, `Semiring` 구조를 Java 제네릭, 전략 패턴, DI와 1:1로 매핑하여 수학적 추상화가 소프트웨어의 OCP로 직결됨을 코드로 증명.
* **알고리즘의 수학적 통합 (다형성):** '경로의 수', '최단 경로', '도달 가능성'이라는 이질적인 문제를 **단일 행렬 거듭제곱 알고리즘으로 통합**하여 상태 교체만으로 다른 문제를 푸는 구조 완성.
* **수학적 정리에 기반한 최적화:** Monoid의 '결합법칙'을 근거로, 비트 연산과 분할 정복을 활용한 **O(log N) 단위의 메모리/연산 최적화 구현**.
